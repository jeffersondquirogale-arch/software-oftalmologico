## 📋 Descripción

OptiSalud es una aplicación web profesional para la gestión integral de un consultorio oftalmológico. Funciona completamente offline, almacenando todos los datos en el navegador del usuario mediante IndexedDB.

## 🚀 Stack Tecnológico

- **React 18** + TypeScript
- **Tailwind CSS** + shadcn/ui
- **Dexie.js** (IndexedDB)
- **Recharts** para gráficas
- **SheetJS** para exportación Excel
- **react-to-print** para impresión
- **React Router v6**
- **Zustand** para estado global
- **Vite** como bundler

## 📦 Módulos

1. Layout Base con sidebar y navegación
2. Base de Datos (Dexie.js)
3. Dashboard con estadísticas
4. Gestión de Pacientes (CRUD)
5. Historia Clínica Digital
6. Perfil del Paciente con gráficas de evolución
7. Impresión de Fórmula Óptica
8. Certificado Médico
9. Agenda de Citas
10. Exportación a Excel

## 🛠️ Instalación

```bash
git clone https://github.com/jeffersondquirogale-arch/software-oftalmologico.git
cd software-oftalmologico
npm install
npm run dev
```
